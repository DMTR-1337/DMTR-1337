### About me

I am an 18 year old Cybersecurity Specialist and Software Developer at **Devodemix Oy** and run **Bittisilta**, a cybersecurity and IT services company in Finland.

I gravitate toward low-level systems programming and building things from the ground up. Rather than importing heavy dependencies, I prefer implementing protocols myself, resulting in small, predictable **C++** libraries consisting of **just a header and an implementation**.

In my security work, I specialize in **penetration testing**, **privilege escalation**, and **web application hardening**, holding a **Top 1% global rank on TryHackMe**.

### Selected Engineering & Security Work

| :--- | :--- | :--- |
| **iPhone Forensics** | `C++` · `USB` · `TLS` · `AFC` | Reads iOS photo libraries directly over USB or from local backups, enumerates *Recently Deleted*, and carves media from caches.
